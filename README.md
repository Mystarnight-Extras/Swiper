# Swiper

Swiper is a browser-based arcade game about timing, focus, and making the right move. Switch lanes to avoid spikes, improve your runs, challenge the bot, play online when matches are available, and create or play community levels.

## Features

- Practice and bot gameplay
- Online quick-play matchmaking and multiplayer lobbies
- Community level editor and browser
- Player profiles and score features
- Leaderboards
- Reporting for players, community levels, and scores
- Responsive browser interface for mobile and desktop

Some online features require an account and an internet connection. Availability of matchmaking depends on other players being online.

## Community and safety

Players are expected to follow the [Community Guidelines](./community-guidelines.html). The game includes reporting tools for player, level, and score reports. Reports are requests for review and do not automatically establish that a rule was broken.

## Project

Swiper is an evolving independent game project. Features and availability may change as the game is maintained and improved.
